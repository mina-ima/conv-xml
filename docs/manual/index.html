e-Gov XML Reader & Assistant 取扱説明書

e-Govからダウンロードした行政手続きのXMLファイルを、読みやすく表示し、AI（Gemini）が内容を分かりやすく解説・整理してくれるツールです。

このアプリでできること

  • e-Govで取得したXMLファイル（ZIP含む）を読み込んで表示します。
  • 内容を要約・通知・お知らせなどの種別ごとに、人が読みやすい形に整理して表示します。
  • XMLの構造をツリー表示で確認できます。
  • AI（Gemini）が内容を解説し、何が書かれているかを分かりやすく示します。
  • 社会保険料などの計算を補助する機能（保険料率の設定・計算ビュー）を備えています。
取り扱う書類の正確な種類や項目はファイル内容に依存します。表示・計算結果は必ず原本（公的書類）でご確認ください。

想定ユーザー・利用シーン

  • 総務・人事・労務の担当者で、e-Govから届くXML書類の中身を素早く把握したい方。
  • 電子申請の控えや通知書の内容を、原文XMLのまま読むのが大変だと感じている方。
  • 社会保険料などの金額をざっと確認・試算したい方。

動作環境・前提

  • PCのWebブラウザ（モダンブラウザ）で動作します。
  • AI解説機能を使うには、Google Gemini のAPIキーが必要です。
  • 自分で動かす場合は Node.js が必要です。

セットアップ

ローカルで動かす場合:

  1. 依存パッケージをインストールします。 
    pnpm install
  2. .env.local に GEMINI_API_KEY を設定します（Google AI Studio で取得したキー）。
  3. 開発サーバーを起動します。 
    pnpm dev

使い方（ステップbyステップ）

  1. アプリを開きます。
  2. e-GovからダウンロードしたXMLファイル（またはZIP）を読み込みます。
  3. 左側で案件・ファイルを選び、右側で内容を確認します。
  4. 表示モードを切り替えて確認します。
    • 要約（summary）: 内容を整理した読みやすい表示。
    • ツリー（tree）: XMLの構造をそのまま確認。
    • 計算（calculator）: 保険料率を設定して金額を試算。
    • 全て（all）: まとめて表示。
  5. AI解説を使うと、書類の意味や要点を日本語で説明してくれます。
  6. 計算ビューでは健康保険・厚生年金・介護保険などの料率を調整して確認できます。

主な機能

  • XML/ZIP 読み込み: 複数ファイル・複数案件をまとめて扱えます。
  • 読みやすい要約表示: 書類種別に応じて項目を整理して表示します。
  • XMLツリービュー: 構造を階層表示で確認できます。
  • AI解説（Gemini）: 内容の意味や要点を日本語で解説します。
  • 計算補助: 保険料率（健康保険・厚生年金・介護保険など）を設定し金額を試算します。全角数字の正規化にも対応します。

よくある質問・トラブルシューティング

  • Q: AI解説が動きません。
    A: GEMINI_API_KEY が設定されているか、無料枠の上限に達していないかを確認してください。
  • Q: ファイルがうまく読めません。
    A: e-Govからダウンロードした正しいXML（またはZIP）かをご確認ください。想定外の書式は正しく整理表示できないことがあります。
  • Q: 計算結果は正確ですか。
    A: 設定した料率に基づく試算です。最終的な金額は必ず公的書類・公式情報でご確認ください。
